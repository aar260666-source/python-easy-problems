# Задача: Средний элемент (медиана из трёх чисел)

**Сложность:** Лёгкая  
**Тема:** Базовые алгоритмы, сравнения, сортировка без встроенных функций  

## Условие

Даны три целых числа `a`, `b` и `c`. Упорядочьте их по возрастанию и выведите число, которое будет стоять между двумя другими (медиану).

### Формат ввода
В единственной строке записаны три целых числа `a`, `b`, `c`, разделённые пробелами.  
Ограничения: $-1000 \le a, b, c \le 1000$.

### Формат вывода
Выведите одно целое число — медиану трёх заданных чисел.

### Примеры

| Ввод | Вывод |
|------|-------|
| `1 2 3` | `2` |
| `1000 -1000 0` | `0` |
| `3 1 3` | `3` |
